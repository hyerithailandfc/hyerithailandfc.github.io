**Hyeri Thailand FC** — an unofficial Thai fan base (บ้านเบส) website about **Hyeri (혜리 / Lee Hye-ri)**, singer (Girl's Day) and actress.
The name lives only in `data/site.json → brand.name`; in UI strings write `{brand}` (filled in by `ui()`), in JS use `brandName()`.
Never hard-code the name elsewhere (static fallbacks in `index.html` / `admin/index.html` excepted).
Static site on **GitHub Pages** — free, no server, no build step. Content comes from the Korean
namu.wiki article (CC BY-NC-SA 2.0 KR), rewritten and translated into **Thai, English and Korean**.

## Hard rules (never break these)
1. **Static only.** Plain HTML/CSS/ES modules served as-is by GitHub Pages. No npm build, no frameworks,
   no server, no database, no paid services. External code only from cdnjs/jsdelivr/unpkg with a pinned version, and only if truly needed.
2. **Three languages, always.** Every piece of user-visible text exists in `th`, `en` and `ko`
   (UI strings in `data/i18n/*.json`, content as `{ "th", "en", "ko" }` objects). Proper nouns may omit `th` (falls back to `en`).
3. **Content lives in `data/*.json`, not in JS/HTML.** Pages read data and render it. The Admin page
   edits these JSON files, so keep them plain and predictable.
4. **Follow the design system** in `docs/design-system.md` — pastel **blue** soft-pop, tokens only, rounded, playful-but-gentle motion,
   `prefers-reduced-motion` respected, works from 320px to wide desktop. Defaults: **Thai** language, **light** theme (dark via toggle).
5. **No copyrighted media copied in.** Never download photos from namu.wiki, news sites or Instagram into the repo.
   Images come only from the admin upload flow or are hotlinked from TMDB via `data/tmdb.json`. Videos are YouTube embeds.
   Never hand-edit `data/tmdb.json` / `data/youtube.json` — they are generated by `tools/sync-external.mjs`.
6. **No scraping namu.wiki.** It blocks bots. Use only text the admin pasted into the issue.
7. **Escape all data** with `esc()` / `tx()` from `assets/js/core.js` when building HTML strings.
8. **Facts must come from the source.** Don't invent dates, ratings, roles or awards. If unsure, ask in the issue.
9. Keep the attribution (source + license) in the footer and About page.
10. Run `node tools/validate.mjs` before committing; it must pass.

## Map of the repo
| Path | What |
|---|---|
| `index.html` | App shell (header, drawer, footer slots) |
| `assets/css/main.css` | Design tokens + all public styles |
| `assets/js/core.js` | Shared helpers: `t`, `tx`, `ui`, `esc`, `icon`, `loadJSON`, `reveal`, `countUp`, dates |
| `assets/js/app.js` | Router, language + theme switching, header/footer |
| `assets/js/pages/*.js` | One module per page (`render()` + optional `mount()`/`unmount()`) |
| `data/site.json` | Source info + **page registry** (adds pages to nav/router) |
| `data/i18n/{th,en,ko}.json` | UI strings |
| `data/profile.json`, `journey.json`, `works.json`, `awards.json`, `media.json`, `girlsday.json` | Content |
| `data/tmdb.json`, `data/youtube.json` | **Generated** posters/synopses/photos (TMDB) and MV/channel data (YouTube) |
| `tools/sync-external.mjs` + `tools/lib/external.mjs` | TMDB/YouTube sync (runs in `.github/workflows/sync-external.yml`) |
| `admin/` | Admin panel (GitHub-token login, editor, Claude requests) |
| `images/gallery/` | Admin-uploaded photos (WebP) |
| `tools/validate.mjs` | Data/registry validator (CI + Claude) |
| `tools/serve.ps1` | Local preview server for Windows |
| `.github/workflows/claude.yml` | Runs Claude on admin requests |
| `package.json` | Only sets `"type": "module"` so Node tools can import `assets/js/core.js` — no dependencies, no build |
